Token Radar (model radar-2) ranks all 198 pre-token protocols in the sealed DefiLlama snapshot by implied value and shows a seven-step farm plan for each, in a filterable dashboard with a live model sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
